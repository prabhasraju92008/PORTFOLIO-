## 📁 File Structure

```

└── README.md      # Documentation & deployment guide
```

---

## 🚀 How to Run Locally

No build tools or Node.js required!

1. Download or extract this folder.
2. Double-click `index.html` to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Everything runs 100% offline with zero dependencies.

---

## 🌐 Deploy to the Web for Free

### Option 1: GitHub Pages
1. Create a new GitHub repository (e.g., `prabhas-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings** → **Pages** → select **main branch** as source and click **Save**.
4. Your site will be live at `https://<username>.github.io/<repo-name>`.

### Option 2: Netlify / Vercel
1. Drag and drop this folder onto [Netlify Drop](https://app.netlify.com/drop) or import to [Vercel](https://vercel.com).
2. Deployed automatically in under 30 seconds!
